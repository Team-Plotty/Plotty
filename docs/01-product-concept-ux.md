# 01. プロダクトコンセプトとUX

## コンセプト

- チャットを単一の窓口として扱う。
- AIが文脈から次の3カテゴリへ半自動振り分けする。
  - `schedule`（日時が明確な予定）
  - `task`（実行すべき行動）
  - `memo`（残しておきたい情報）

## ハイブリッド入力

- 事前カテゴリ選択: 送信前にユーザーがカテゴリを明示可能。
- AI推論アシスト: 入力中の予測をUIで提示。
- 後付け修正: 送信後の再分類を可能にする。
- 30日経過で元メッセージが消えた後は、相対参照の修正は受け付けない。

## UXフロー

1. 入力（自由文 + 必要ならカテゴリ指定）
2. 解析・登録（AI抽出 -> 実データ作成）
3. 確認（チャット内確認）
4. ストック（カレンダー/リストで管理）

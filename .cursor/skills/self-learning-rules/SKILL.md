# 自己学習ルール（.cursorrules追記）

## 目的
ユーザーが明確に「間違い/中止」を示したとき、同じ失敗を繰り返さないために、プロジェクトの `.cursorrules` に失敗メモを自動追記してから返答する。

## トリガー
ユーザーの発言に次のいずれかが含まれる場合:
- 「それは間違い」
- 「やめて」
- 「ダメ」

## 必須動作（最優先）
トリガーを検知したら、**必ず次の順番**で行う。

1. `.cursorrules` を開いて、`## 過去の失敗メモ` セクションを探す
2. そのセクションの先頭（または直下）に、次の形式で1行追記する（新しいものが上）
3. 追記後に、ユーザーへの返答（修正案/代替案/以降の対応）を続ける

### 追記フォーマット（厳守）
次の1行形式のみ:
- `- YYYY/MM/DD: [何をしたら] → [何が起きた] → [正しい対処]`

#### 記入ガイド
- `YYYY/MM/DD` はローカル日付で記入する
- `[何をしたら]` は自分が行った行為（例: 〜を勝手に実行した、〜を削除した、〜を憶測で断定した）
- `[何が起きた]` はユーザーにとっての不利益（例: 意図と違う変更、時間の浪費、混乱、壊れた）
- `[正しい対処]` は次回の具体的な行動（例: 事前確認する、読み取りで根拠を示す、変更を止めて代替案を提示する）

## エラー時の扱い
- `.cursorrules` が存在しない場合: 作成して「自己学習ルール」と「過去の失敗メモ」セクションを用意してから追記する
- `## 過去の失敗メモ` が見つからない場合: 末尾にその見出しを追加し、その直下へ追記する

## 例
ユーザー: 「やめて」

追記:
- `- 2026/05/04: [検証せずにコマンド実行を提案した] → [意図しない変更の不安を与えた] → [実行前に目的/影響/代替を短く確認してから進める]`
